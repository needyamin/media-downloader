What the project does

This repository centers on a main desktop app launched through run.py. The app downloads media from supported public sources, handles playlist workflows, offers format and quality controls, and opens extra tools from the same interface.

At a glance
  • Main launcher: run.py
  • Main app: src/desktop_tools/app/media_download.py
  • Shared modules: shared/ffmpeg.py and shared/resources.py
  • Windows packaging: Nuitka + Inno Setup
  • Linux packaging: PyInstaller + AppImage

Main app

Media Downloader

The main window handles URL entry, progress tracking, playlist control, logs, and the top-level workflow.

  • Launches through run.py
  • Implements the downloader UI and tray behavior
  • Acts as the entry point for companion tools
Companion tool

Video Converter

Opened from the app menu and uses the shared FFmpeg runtime for conversion work.

  • File: converter_app.py
  • Menu path: Tools -> Video Converter
  • Designed to stay responsive while FFmpeg prepares in the background
Companion tool

BG Remover

A second integrated utility that lives inside the same desktop product and project structure.

  • File: background_remover_app.py
  • Menu path: Tools -> BG Remover
  • Shares packaging, assets, and release flow with the main app
Companion tool

Screenshot Studio

Capture the full screen or a selected region, then mark up the result with polished annotation tools before exporting.

  • File: screenshot_app.py
  • Menu path: Tools -> Screenshot Studio
  • Includes pen, arrows, circles, border boxes, triangles, undo/redo, and a color picker
Build overview

Release paths kept simple

Windows builds compile the app with Nuitka and wrap it with Inno Setup. Linux builds produce a PyInstaller bundle and package it as an AppImage. The same repo also supports AppImage creation from Windows by calling Ubuntu WSL directly.

  • Windows output: release/windows
  • Linux output: release/linux
  • Linux artifact: Media-Downloader-x86_64.AppImage
Windows build

Nuitka + Inno Setup

Build the Windows executable and installer from the project root.

python "src\desktop_tools\app\nutika_build.py"
Linux build

Native Linux or Ubuntu WSL

Use Linux directly, or run the same flow through Ubuntu WSL from Windows.

python3 "src/desktop_tools/app/linux_appimage_build.py"

wsl.exe -d Ubuntu -u root -- sh -lc "apt-get update && DEBIAN_FRONTEND=noninteractive apt-get install -y python3-pip python3-venv python3-dev python3-tk build-essential patchelf file zsync libglib2.0-0 libnss3 libgtk-3-0 libx11-6 libxkbcommon0 libdbus-1-3 libasound2t64 libtbb12"
wsl.exe -d Ubuntu -- sh -lc "cd /mnt/c/path/to/media-downloader && python3 -m venv .venv-wsl && . .venv-wsl/bin/activate && python src/desktop_tools/app/linux_appimage_build.py"

Runtime configuration

Lightweight behavior can be tuned from app_flags.json.

  • debug_logging reduces extra internal noise when set to false
  • disabled_domains blocks selected domains even if they are supported
  • Other flags adjust queue polling, clipboard timing, and log limits
