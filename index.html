Free & Open Source

One app to download, convert, capture & companion

Media Downloader is a free desktop app with 7 tools in one hub: stream downloads, an IDM-style download queue, video conversion, AI background removal, screenshots, screen recording, and Anika — an optional desktop mascot with break reminders.

Works on Windows and Linux. No account needed. No ads. MIT licensed.

Download for Windows Linux AppImage GitHub

What can you do with it?

Core workflows in one app — pick what you need.

Download Videos

Paste a URL → choose quality → download. Playlists supported. Clipboard can auto-detect links.

Download List

Queue direct file links — pause, resume, replace broken URLs, and manage history (IDM-style).

Convert & Edit

Convert video formats and remove image backgrounds with built-in AI tools.

Capture Screen

Take screenshots or record your screen with region selection and annotation tools.

How it works

No technical knowledge required. Just install and go.

1

Install the app

Download MediaDownloader_Setup.exe on Windows or the AppImage on Linux. The installer bundles the full standalone app — no extra Python install needed.

2

Paste a link or open a tool

Paste a video URL to download it, open the Download List for direct files, or launch any tool from the menu — converter, BG remover, screenshot, recorder, or Anika.

3

Done — files saved to your folders

Videos, audio, and files are auto-organized into neat folders. Screenshots and recordings save instantly.

What's inside each workflow

Each mode is built for a specific task — here's what you get.

Video & Audio Downloads

Download from many public video sites using yt-dlp under the hood. You just paste a link.

  • Choose video quality and audio bitrate
  • Download full playlists with a file limit
  • Clipboard auto-detects supported links
  • Output sorted into video/, audio/, playlists/

Download List (IDM-style)

For direct file links — .mp4, .mp3, .zip, .exe, images, archives. Works like Internet Download Manager.

  • Icon toolbar: add URL, resume, pause, open file/folder, and more
  • Queue multiple downloads at once
  • Pause, resume, cancel, and replace broken links
  • Persistent history across sessions

Video Converter & BG Remover

Two processing tools that share the same FFmpeg engine, managed automatically.

  • Batch convert videos with quality presets
  • Classic u2net model by default — fast and offline-ready
  • Premium AI models (BiRefNet, BRIA) — download only when you choose
  • Live download progress for large ONNX models
  • FFmpeg installs and updates itself

YScreenshot & YScreenRecorder

Built-in capture tools — no need to install separate screenshot or recording software.

  • Select a region or capture full screen
  • Annotate screenshots before saving
  • Record with a transparent floating HUD
  • Pause, resume, and auto-open output folder

Meet Anika

Optional desktop companion for Windows — break reminders, spell book, timer, and personality.

Break reminders

Configurable interval and how long she stays on screen when it is time to rest.

Edge hide & peek

Drag Anika to a screen edge to tuck her away; hover the edge to peek back.

Hub integration

Ctrl+Shift+U or Tools → Anika. Windows builds include Anika.exe beside the main app.

Download & get started

Choose your platform. Everything is bundled — no extra setup needed.

⊞ Windows

Download MediaDownloader_Setup.exe from GitHub Releases. Nuitka standalone + Inno Setup — all 7 tools, Anika.exe, bundled assets, and auto-managed FFmpeg. Installed apps check for updates and can install a newer release silently (updates.packaged_auto_update). Releases ship compiled binaries only (no source archive).

Download for Windows

🐧 Linux

Download Media-Downloader-x86_64.AppImage, run chmod +x, then launch. For full screenshot/recorder support, install host packages such as ffmpeg, python3-tk, xclip, wl-clipboard, grim, and scrot.

Download AppImage

🛠 Build from source

Clone the repo, then install deps and run the hub:

pip install -r src/desktop_tools/app/requirements.txt
python run.py

Windows: python -m desktop_tools.app.build_tools.nuitka · Linux AppImage: python -m desktop_tools.app.build_tools.linux_appimage. Use Python 3.12–3.13 for Nuitka. Tag v2.0.1 → GitHub Actions builds and publishes the release.

Full README guide

⚙ Configuration & data

Edit app_flags.json for hotkeys, domains, and updates. App data lives under %LOCALAPPDATA%\Media Downloader\ (Anika settings, rembg models, ffmpeg cache). Uninstall removes that folder — not your Downloads.
